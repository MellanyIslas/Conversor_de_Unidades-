# Conversor_de_Unidades-

Este es un repositorio que convierte una temperatura dada en grados Celsius a su equivalente en grados Fahrenheit.

## Descripción del Script

El script `conversor_temperatura.py` pide al usuario que ingrese una temperatura en grados Celsius. Utiliza la fórmula matemática estándar $F = (C \times 9/5) + 32$ para realizar la conversión y muestra el resultado en pantalla.

## Cómo Utilizar el Script

Puedes usar este conversor siguiendo estos pasos:

1.  **Clona o descarga el archivo `conversor_temperatura.py`.**
    ```bash
    git clone [URL-de-tu-repositorio]
    ```

2.  **Abre tu terminal y navega al directorio donde guardaste el archivo.**
    ```bash
    cd [nombre-del-directorio]
    ```

3.  **Ejecuta el script:**
    ```bash
    python conversor_temperatura.py
    ```

4.  **Ingresa la temperatura:** Cuando el programa te lo pida, escribe el valor en grados Celsius que deseas convertir.

    **Ejemplo de uso:**
    ```
    --- Conversor de Temperatura: Celsius a Fahrenheit ---
    Ingresa la temperatura en grados Celsius: 25

    25.0°C equivale a 77.00°F
    ```
